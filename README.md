# Project «СКЗС Стройка» — Интеллектуальная RAG-система автоматизации строительных смет

![AI Automation](https://img.shields.io/badge/AI-Integration-blue?style=for-the-badge)
![RAG Architecture](https://img.shields.io/badge/Architecture-RAG_Model-orange?style=for-the-badge)
![Business Impact](https://img.shields.io/badge/Business_Impact-Time_Optimization-green?style=for-the-badge)

Профессиональное решение класса **Enterprise Knowledge Management & Process Automation** для строительной компании «Золотое Сечение» (СКЗС, г. Ростов-на-Дону). Система представляет собой кастомного ИИ-агента на базе LLM (Claude), реализующего концепцию **RAG (Retrieval-Augmented Generation)** для мгновенного извлечения данных из архитектурных проектов (PDF) и автоматического расчета промежуточных строительных смет.

---

## 📋 Бизнес-контекст и проблематика

В индивидуальном жилищном строительстве (ИЖС) подготовка первичных коммерческих предложений (КП) традиционно является «узким горлышком»:
* **Высокие временные затраты:** Ручной просчет объемов по чертежам разделов АР (Архитектурные решения) и КР (Конструктивные решения) занимает от нескольких часов до 2–3 дней.
* **Человеческий фактор:** Высокий риск пропустить скрытые работы (армопояса, гидроизоляцию, сопутствующие накладные расходы).
* **Потеря лидов:** Задержка в выдаче стоимости клиенту снижает конверсию на первом этапе воронки продаж.

**Решение:** Проект «СКЗС Стройка» автоматизирует рутинную аналитическую работу сметчика, преобразуя проектную документацию в структурированный финансовый документ за считанные минуты.

---

## 🎯 Ключевые метрики эффективности (KPI)

* ⏳ **Скорость расчета:** Сокращение времени подготовки детальной промежуточной сметы с **нескольких часов до 5–15 минут**.
* 🎯 **Точность:** Целевая точность расчетов составляет **±10–15%** для типовых объектов (кирпич, газоблок) и **±25%** для нестандартных архитектурных решений премиум-сегмента.
* 📊 **Полнота:** Автоматическое формирование **24 технологических разделов сметы** в строгом соответствии с корпоративным шаблоном компании.

---

## 🏗️ Архитектура системы (Трехуровневая модель RAG)

Система функционирует как изолированная интеллектуальная среда (Project Environment), архитектура которой разделена на три взаимосвязанных слоя:

```
┌────────────────────────────────────────────────────────┐
│                   INSTRUCTIONS LAYER                   │
│        (Системный промпт: роль, логика, законы)       │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│                 KNOWLEDGE BASE LAYER                   │
│  (12 структурированных файлов: ФОТ, МАТ, Правила, БЗ)   │
└───────────────────────────┬────────────────────────────┘
                            ▼
┌────────────────────────────────────────────────────────┐
│                   USER PROMPT LAYER                    │
│   (Интерфейс менеджера: анкета объекта + PDF проекта)   │
└────────────────────────────────────────────────────────┘
```

### 1. Слой Instructions (Системные правила и ограничения)
Жестко детерминирует роль ИИ как ведущего сметчика компании. Содержит встроенные запреты на использование внешних (галлюцинированных) расценок, правила сокрытия внутренней маржинальности (себестоимость, коэффициенты) и регламент вывода данных исключительно в ценах для клиента (коэффициент дельты = 1.15).

### 2. Слой Knowledge Base (Корпоративная база знаний)
Справочный фундамент системы, состоящий из 12 оптимизированных файлов данных и регламентов:
* **Базы расценок ФОТ (Фонд оплаты труда) и МАТ/МЕХ (Материалы и Механизмы):** Матрицы цен, декомпозированные по технологическим этапам, с динамическими уровнями доверия (калибровка на основе 6 реальных построенных объектов-эталонов: *Малахитовая, Жукова, Грушевский, Гагик, СНТ Строитель, Озёрная*).
* **Системные правила расчёта:** Алгоритмы вычета оконных/витражных проемов из площади фасадов, правила расчета кровельных разуклонок, специфика учета монолитных конструкций выше и ниже нуля.
* **Методология и Формат вывода:** Пошаговый конвейер (7 шагов) обработки контекста и шаблон визуализации документа (6 обязательных блоков от сводной таблицы до рекомендаций для встречи с клиентом).

### 3. Слой User Prompt (Пользовательский интерфейс)
Стандартизированный шаблон анкеты для менеджеров по продажам. Заполняется минимальными вводными данными по объекту (площадь, этажность, тип конструктива) и передается в систему вместе с «сырым» чертежом здания.

## 🛠️ Технологический стек и методология

* **Core AI:** Large Language Models (LLMs) с расширенным контекстным окном, оптимизированные под Prompts Engineering сложных инженерных документов.
* **Data Management:** Систематизация баз данных расценок в форматах табличных структур данных (`.xlsx`, `.csv`), версионирование данных.
* **System Analysis:** Оцифровка бизнес-логики (Регламент обновления БЗ, Буфер отложенных правок, управление аномалиями и пометками `[ТРЕБУЕТ УТОЧНЕНИЯ]`).

---

## 🔄 Реализованный конвейер обработки данных (Методика расчёта)

1. **Экстракция контекста:** ИИ анализирует прикрепленный PDF-проект, сопоставляя геометрические параметры чертежей с анкетой менеджера.
2. **Поиск аналогов:** Валидация объекта по матрице эталонов (выбор релевантного класса здания: от малых газоблочных до монолитно-каркасных премиум-объектов площадями 400+ м²).
3. **Логический расчет объемов:** Применение зафиксированных математических формул (вычисление объемов стен, площадей скатов кровли, объемов бетона).
4. **Калькуляция стоимости:** Построчный маппинг объемов с Базами расценок ФОТ и МАТ.
5. **Многоэтапная самопроверка:** Сверка суммарных объемов сметы с проектными спецификациями для исключения пропусков.
6. **Генерация финального документа:** Форматирование вывода в 6 бизнес-блоков в репрезентативном стиле компании.

---

## 📈 Бизнес-результаты внедрения

* **Ускорение процессов бизнес-анализа:** Скорость первичной оценки стоимости объекта выросла в **12-15 раз**.
* **Разгрузка инженерного отдела:** Освобождение времени главных сметчиков и инженеров от рутинной калькуляции типовых КП для переключения на сложные коммерческие тендеры.
* **Инструмент аргументации:** Блок автоматических «Рекомендаций для встречи» снабжает менеджера по продажам списком неочевидных особенностей проекта, повышая его экспертный статус в глазах заказчика на этапе переговоров.
